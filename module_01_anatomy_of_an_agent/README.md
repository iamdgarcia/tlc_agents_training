# Module 1: The Anatomy of an Agent (Theory & First Agent) 🧠

In this module, we dive into the internal architecture of an AI agent and build our first simple agent.

## 📚 Topics
*   **1.1 The Agent Loop**: Perception, Reasoning, Action, and Memory.
*   **1.2 Agent Reasoning**: Prompt Engineering techniques for agents (Zero-shot, Few-shot).
*   **1.3 The ReAct Pattern**: Understanding Reasoning and Acting.
*   **1.4 The Action Layer**: How agents use tools and functions.

## 🎯 Learning Objectives
*   Explain the four main components of an AI agent.
*   Implement a basic ReAct loop.
*   Create an agent that can use a simple tool (e.g., a calculator).
