# Appendix: Resources and Next Steps 📚

## Glossary
*   **Agent**: An AI system that can reason and take actions.
*   **LLM**: Large Language Model (e.g., GPT-4).
*   **RAG**: Retrieval-Augmented Generation.
*   **ReAct**: Reasoning + Acting pattern.
*   **Vector DB**: A database for storing embeddings.

## Next Steps
1.  **Build a Portfolio**: Create 3-4 agents that solve real problems (e.g., a stock market analyzer, a travel planner).
2.  **Deploy**: Learn how to deploy your agents using Streamlit or FastAPI.
3.  **Contribute**: Look for open-source agent projects on GitHub.
