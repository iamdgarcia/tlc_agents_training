# Module 2: Memory and Context Management 💾

This module explores how to give agents memory and access to external knowledge.

## 📚 Topics
*   **2.1 Types of Agent Memory**: Short-term context vs. Long-term storage.
*   **2.2 Retrieval-Augmented Generation (RAG)**: The basics of RAG.
*   **2.3 RAG for Agents**: Building a "Chat with Your Docs" agent.

## 🎯 Learning Objectives
*   Implement conversation history for a chatbot.
*   Set up a simple vector store for RAG.
*   Build an agent that can answer questions based on a document.
