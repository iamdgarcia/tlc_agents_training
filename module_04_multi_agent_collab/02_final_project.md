# 4.2 Final Project: The Autonomous Workflow Agent 🚀

Congratulations! You've made it to the final project.

We are going to build a **Content Creation Pipeline**.

## The Goal
Input: A topic (e.g., "The benefits of meditation").
Output: A polished blog post in markdown format.

## The Team
1.  **Planner**: Breaks the topic into an outline.
2.  **Researcher**: Finds information for each section of the outline.
3.  **Writer**: Writes the content based on the research.
4.  **Editor**: Reviews the content and fixes tone/grammar.

## The Code
The file `final_project.py` contains the complete implementation. It uses a sequential chain where the output of one agent becomes the input of the next.
