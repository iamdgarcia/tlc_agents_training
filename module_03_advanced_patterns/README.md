# Module 3: Advanced Agent Design Patterns 🏗️

Here we cover advanced patterns that allow agents to handle complex tasks and improve their own performance.

## 📚 Topics
*   **3.1 Hierarchical Planning**: Breaking down complex goals.
*   **3.2 Reflection and Self-Correction**: Agents that critique and improve their output.
*   **3.3 Multi-Agent Systems (MAS)**: Introduction to collaborative agents.

## 🎯 Learning Objectives
*   Implement a sequential workflow.
*   Build a reflective agent that self-corrects.
*   Understand the roles in a multi-agent system.
