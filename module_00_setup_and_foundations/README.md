# Module 0: Setup and Foundations (The Toolkit) 🛠️

This module covers the essential tools and concepts you need to get started with Agentic AI.

## 📚 Topics
*   **0.1 Welcome & Course Roadmap**: Understanding the shift from "Chat" to "Do".
*   **0.2 Core Building Blocks**: Introduction to LLMs and installing key libraries (`langchain`, `crewai`, etc.).
*   **0.3 API Key Management**: Securing your API keys and managing costs.

## 🎯 Learning Objectives
*   Set up a Python development environment for AI agents.
*   Understand the basic architecture of an LLM-based application.
*   Securely manage API keys using `.env` files.
