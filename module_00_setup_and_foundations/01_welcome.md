# 0.1 Welcome & Course Roadmap 🗺️

## 👋 Welcome to Agentic AI!

Welcome to the exciting world of **Agentic AI**. If you've used ChatGPT or Claude, you've experienced the power of **Generative AI**—systems that can generate text, code, and images.

**Agentic AI** takes this a step further. Instead of just *saying* things, Agents can *do* things. They can:
*   Search the web for real-time data.
*   Read and write files.
*   Execute code.
*   Interact with other software APIs.

In short: **LLMs are the brain; Agents are the brain with hands.**

## 🛣️ The Roadmap

This course is designed to be a practical, code-first journey.

1.  **Module 0: The Toolkit** - We'll set up our environment and get our API keys ready.
2.  **Module 1: Anatomy of an Agent** - We'll build a simple agent from scratch to understand the core loop: *Think -> Act -> Observe*.
3.  **Module 2: Memory & Context** - We'll teach our agents to remember past conversations and read documents (RAG).
4.  **Module 3: Advanced Patterns** - We'll explore planning, reflection, and self-correction.
5.  **Module 4: Multi-Agent Systems** - We'll orchestrate a team of agents to work together.

## 🛠️ Prerequisites

*   **Python**: Basic knowledge of Python (variables, functions, loops).
*   **Git**: Basic familiarity with cloning repos.
*   **Curiosity**: A willingness to experiment and break things!

Let's get started!
